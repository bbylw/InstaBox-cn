# 定价与用量

> 套餐包含什么，以及每一项用量的单价。

机器只在运行时按秒收取 vCPU 和内存费用。暂停或关机的机器只收磁盘费用（macOS 机器的 Mac 租约无论开关机都按 24 小时起租）。付费套餐包含月度额度，用量先从额度里扣。所有价格以美元计。

| **Builder** | $100/月 + 用量 | $100 月度额度，最多 200 台并发，最高 16 vCPU / 32 GiB，磁盘最高 500 GiB，包含 1 TiB 磁盘，无限快照，5 TiB 出站流量/月 |

## 单价

超出月度额度的部分按下列单价付费。运行时按秒计费，只在机器运行时收取。快照免费。

| 资源 | 价格 | 单位 |
| --- | --- | --- |
| vCPU | $0.004 | 每 vCPU·小时 |
| 内存 | $0.00225 | 每 GiB·小时 |
| 存储 | $0.00011 | 每 GiB·小时 |
| 出站流量 | $0.02 | 每 GiB |

**存储**：免费套餐的磁盘不额外收费。付费套餐按所有机器合计包含磁盘额度（Pro 200 GiB、Builder 1 TiB、Team 5 TiB）；超出部分按已分配的 `/data` 以 $0.08/GiB·月计费。

## 常见问题

**我在为什么付费？**
机器运行时，为你分配给它的 vCPU 和内存付费。暂停后就只为磁盘付费。快照免费。

**额度怎么用？**
用量先扣套餐包含的额度，超出后按量付费。额度每月重置。

**流量收费吗？**
入站流量始终免费。每个套餐包含月度出站流量（Free 100 GiB、Pro 1 TiB、Builder 5 TiB、Team 50 TiB），超出后 $0.02/GiB。

**早期账号的 5 台免费沙箱呢？**
2026-10-20 之前注册、并在 2026-10-25 07:45 UTC 之前激活的账号，可获得 5 台免费沙箱直到 2026-12-01 00:00 UTC。之后同一时间只有一台免费沙箱运行，其余会被暂停而不是删除。想跑另一台，可以暂停当前那台再启动，或删除不需要的机器，或升级套餐。

## GPU

GPU 机器像普通机器一样为 vCPU 和内存付费，并额外为 GPU 付费。GPU 按块、按秒计费，只在机器运行时收取。暂停或关机的 GPU 机器不占用 GPU，只收磁盘费用。GPU 用量同样先从月度额度里扣。

| GPU | 价格 | 每块 GPU 的规格 | 每块 GPU 全包价 |
| --- | --- | --- | --- |
| NVIDIA L4（`l4`） | $0.80 / GPU·小时 | 11 vCPU / 36 GiB | $0.925 / 小时 |

例如，带两块 NVIDIA L4 的机器运行时每小时 $1.85。GPU 机器仅付费套餐可用。

## macOS 机器

macOS 机器把一个完整的 Mac 租给工作区，按小时计价。价格已包含机器的 vCPU 和内存，不再额外计费；磁盘按存储计费。租约至少 24 小时，无论机器是否运行，之后按秒计费。macOS 机器需要 Pro 或更高套餐。

| 型号 | `--model` | 每小时 | 24 小时最低 |
| --- | --- | --- | --- |
| M2 Pro | `m2pro` | $0.85 | $20.40 |
| M4 Pro | `m4pro` | $1.25 | $30.00 |
| M4 | `m4` | $0.75 | $18.00 |
| M2 | `m2` | $0.45 | $10.80 |

## 查看本月用量

```bash
instabox usage
```

```bash
curl https://api.instabox.sh/v1/usage -H "X-API-Key: $INSTABOX_API_KEY"
```

返回内容包括机器与快照数量、存储占用、本月费用和额度余额。`GET /v1/machines/{id}/usage` 返回单台机器本月的运行秒数。
